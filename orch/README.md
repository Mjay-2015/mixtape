## What was changed
A subset was picked (one sample every 3–4 semitones, a forte dynamic layer, the first round robin), then each
file was mixed to mono, trimmed (long notes 4 s, short notes 1.5 s, plucked 3 s, struck 4 s) with a short fade,
and normalised per articulation to peak at -3 dBFS. 16-bit, 44.1 kHz WAV. `index.json` maps MIDI notes to files.
