# Grand piano

Salamander Grand Piano V3 by **Alexander Holm** (Yamaha C5), licensed under
Creative Commons Attribution 3.0 Unported (CC-BY 3.0, full text in LICENSE.txt).
Source: https://archive.org/details/SalamanderGrandPianoV3, via the SFZ edition at
github.com/sfzinstruments/SalamanderGrandPiano (commit 3382bf9496bba2486f5ab0de55a264d1dfc38404).

Changes made for Mixtape: 30 notes (every minor third, A0 to C8) at 4 of the 16
velocity layers (2, 7, 11, 16), retuned with the edition's per-note tuning table (Markus Fiedler), mixed to mono, trimmed (3.5 to 9 seconds by
register, 0.4 s fade), scaled by one common gain, saved as 16-bit FLAC.
